## M1 — Спайк броска (технический риск №1) ✅
Цель: доказать, что бросок приятен сам по себе, а физика маленькой кости устойчива и детерминирована.
- [x] `Packages/AsyqPhysics`: Jolt 5.6.0 вендорим, свой C-фасад (не joltc), сборка для устройства и симулятора, флаг детерминизма (ADR-002)
- [x] Тесты пакета: кость падает и засыпает, CCD, контакты, материалы, снимок/восстановление мира; результат бит в бит совпадает на Mac и в симуляторе iOS
- [x] Временная кость — скруглённый «камешек» с шестью сторонами; меш и физика — одна и та же форма (ADR-009)
- [x] `ArenaMetalView` (порт `GlobeMetalView`): до 120 Гц, рисование по требованию
- [x] Сцена: войлок, разметка «нитью», кон из 15 кенеев, мягкие тени (shadow map + контактные тени), дымка-циклорама
- [x] Шаг 240 Гц + интерполяция, CCD у всех костей. Масштаб мира ×10 спрятан в пакете
- [x] `ThrowGesture` (рогатка) → `ThrowInput(angle, power, spin)`, предпросмотр места приземления на ковре
- [x] Хаптика на Core Haptics: натяжение, отпуск, удары по силе, «шықты»
- [x] Камера: прицел за спиной → преследование сақи → облёт удара в slow-mo → умный общий план, который ведёт катящиеся кенеи
- [x] `PoseClassifier` + тесты на шесть положений
- [x] Тест частот: 600 иіру на временной кости (широкие > узкие > торцы). Настоящая калибровка — по сканам в M3
- [x] Тест детерминизма: один ввод → одинаковое состояние; входы физики только через `SimMath`
- [x] DEBUG-аргументы (`CLAUDE.md`)
- [x] Сверх плана: судья «выбит/не выбит», серия с края круга, возврат кенеев после промаха, выкрики «ШЫҚТЫ!» / «ТИМЕДІ» и сторона сақи
