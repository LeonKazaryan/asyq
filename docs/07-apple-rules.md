# 07 · Правила Apple

Два свода: **Human Interface Guidelines** (как выглядеть и вести себя; влияет на шанс попасть в подборки) и **App Review Guidelines** (за что отклоняют). Плюс технические требования. ✅ — уже соблюдено.

## HIG — что важно для игры

| Правило | Как соблюдаем |
|---|---|
| Зоны касания ≥ 44×44 pt | Все кнопки меню и HUD. Зона рогатки — вся нижняя половина экрана |
| Не перехватывать системные жесты | Рогатка не начинается у нижнего края (полоска «домой») и у боковых краёв. Учесть в `ThrowGesture` |
| Safe Area | Сцена на весь экран, HUD и кнопки внутри safe area |
| Reduce Motion | Без облёта камеры и slow-mo, склейка на вид сверху |
| Хаптика — подтверждение действия | Хаптика только от реальных событий (натяжение, удар), выключается в настройках, уважает системную |
| Звук | Учитываем беззвучный режим (`AVAudioSession` категории `.ambient`) — музыка в наушниках у человека не прерывается |
| Dynamic Type, VoiceOver | Меню, «Ереже», итоги. См. [02-design.md](02-design.md#доступность) |
| Пауза | Игра встаёт на паузу при уходе в фон и при звонке, бросок не теряется |

## App Review — риски

| Пункт | Риск | Что делаем |
|---|---|---|
| 1.1 Культурный контент | Национальная тема, тон | Вычитка носителем, никаких штрафов из дворовых игр и гадания |
| 1.3 Kids Category | Аудитория включает детей | В Kids-категорию **не** идём (её правила мешают будущим ссылкам-вызовам). Рейтинг 4+, без рекламы, без сбора данных |
| 2.1 Полнота | Недоделанные режимы | Никаких «Скоро» и заблокированных пустых экранов в релизе |
| 2.3 Метаданные | Скриншоты должны показывать реальную игру | Снимаем `Tools/Screenshots` из настоящих сцен |
| 3.1.1 Покупки | Если появятся (v1.1+) | Только через In-App Purchase, без внешних ссылок на оплату |
| 4.2 Минимальная функциональность | — | Полноценная игра, не риск |
| 5.1 Приватность | — | «Данные не собираются», без сторонней аналитики и SDK. Политика конфиденциальности всё равно обязательна |
| 5.2 Интеллектуальная собственность | Регламент и символика федерации | Правила (факты) используем, логотипы и имена настоящих спортсменов — нет |

## Технические требования

- Сборка последним Xcode/SDK, который требует App Store Connect на момент отправки.
- `ITSAppUsesNonExemptEncryption = NO` ✅ (своего шифрования нет).
- **Privacy manifest** (`PrivacyInfo.xcprivacy`): `UserDefaults` и SwiftData требуют объявить причины использования «required reason API». Сделать в M9.
- Иконка 1024×1024 со светлым, тёмным и tinted вариантами.
- Лицензия Jolt (MIT) — текст в разделе «О приложении».
