# 06 · Конвенции и процесс

## Код

### Общее
- [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/): понятные имена, без сокращений.
- Один главный тип на файл, файл называется по типу: `BesTabanRules.swift`.
- Доступ по умолчанию максимально закрытый.
- Комментарии объясняют **почему**, а не **что**. Если код следует пункту Регламента, ссылка на страницу: `// Регламент, с. 63: …`.
- Код, имена и комментарии — на английском. Документация — на русском.

### Казахские термины в коде
Игровые термины не переводим, а транслитерируем латиницей без диакритики. Так код читается рядом с Регламентом.

| Термин | В коде |
|---|---|
| Асық, сақа, кеней | `asyk`, `saqa`, `kenei` |
| Алшы, тәйке, бүк, шік, омпы, шоңқай | `alshy`, `taike`, `buk`, `shik`, `ompy`, `shonqai` |
| Иіру, ату | `iiru`, `atu` |
| Бес табан, табан | `besTaban`, `taban` |
| Шыр, жұп, Өлді, Жаттым | `shyr`, `jup`, `oldi`, `jattym` |
| Кон, шеңбер | `kon`, `circle` (общее слово — по-английски) |
| Жол, Қалта, Ереже | `Jol`, `Qalta`, `Ereje` |

### SwiftUI
- Маленькие View: если `body` больше ~80 строк, выносим части.
- `@State` всегда `private`. У экранов и компонентов есть `#Preview`.
- Цвета, шрифты, анимации, хаптика — **только из DesignSystem**. Никаких `Color(red:…)` и `.spring(duration: 0.37)` в фичах.
- Числа ощущений и физики — **только в `Tuning/GameTuning.swift`**.
- Все строки — через String Catalog (`Localizable.xcstrings`).
- Reduce Motion: `@Environment(\.accessibilityReduceMotion)` в каждой новой анимации.

### Swift 6
- UI, рендер, основной мир физики — `@MainActor`. Бот — свой `actor`.
- Никаких `try!` и force unwrap, кроме загрузки ресурсов из бандла при старте (`fatalError` с понятным сообщением).
- API новее iOS 18 — только под `if #available`.

## Git

- `main` всегда собирается и работает. Работа в ветках: `feature/throw-spike`, `fix/kenei-out-detection`.
- Коммиты на английском, [Conventional Commits](https://www.conventionalcommits.org/): `feat(physics): add jolt facade`, `fix(rules): restore kenei after miss`, `docs: update roadmap after M1`.
- **Коммитит Leon.** Claude пишет код и предлагает текст коммита.
- Релизы — теги `v1.0.0`.

### Версии
- `MARKETING_VERSION`: `0.x` до релиза, `1.0.0` на релизе, дальше semver.
- `CURRENT_PROJECT_VERSION` (билд): +1 при каждой загрузке в TestFlight.

## Как работаем вместе (Leon + Claude)

1. **Берём задачу** — следующий пункт из [04-roadmap.md](04-roadmap.md).
2. **Claude коротко описывает подход,** если задача неочевидная. Решает Leon.
3. **Claude пишет код** и сам проверяет сборку и тесты (`xcodebuild`).
4. **Leon запускает на iPhone** и говорит про ощущения: «нет веса», «резко», «хочу ещё отскока». Для броска и анимаций это главный этап.
5. **Итерируем** параметры в `GameTuning`, пока не станет «вау».
6. **Обновляем доки:** галочки в роадмапе, решения в журнал ADR, толкования правил в [05-rules.md](05-rules.md).
7. **Leon коммитит.**

## Шпаргалка по Xcode

| Действие | Как |
|---|---|
| Запустить / остановить | `⌘R` / `⌘.` |
| Тесты | `⌘U` |
| Очистить сборку | `⇧⌘K` |
| Быстро открыть файл | `⇧⌘O` |
| Preview (Canvas) | `⌥⌘↩`, обновить `⌥⌘P` |
| Перейти к определению | `⌃⌘J` или `⌘`+клик |
| Профилировать (Instruments) | `⌘I` |
| GPU-кадр Metal | Debug → Capture GPU Workload |

Если Xcode «сошёл с ума»: `⇧⌘K`, перезапустить Xcode, удалить DerivedData проекта.
